**IconButton** — icon-only action for toolbars and compact UI. Always pass `label` for accessibility.

```jsx
<IconButton label="Menu" variant="tertiary"><i data-lucide="menu"></i></IconButton>
<IconButton label="Next" variant="primary" shape="circle"><i data-lucide="arrow-right"></i></IconButton>
```

Variants: `primary` / `secondary` / `tertiary` (outlined) / `ghost`. Shapes: `circle` (default) / `square`. Sizes `sm`/`md`/`lg` (32/40/48px).
