**Badge** — small pill status label.

```jsx
<Badge variant="brand">Case Study</Badge>
<Badge variant="success">Success</Badge>
<Badge variant="error" size="sm">Error</Badge>
```

Variants: `default`, `brand` (yellow), `success` (green), `error` (red), `info` (blue), `accent` (pine). Sizes `sm`/`md`. For removable/interactive labels use `Tag`.
